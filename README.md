# A Second Brain for Land Deals

A one-page guide to keeping an Obsidian "second brain" with an AI assistant, written for a timber-and-land investor who buys timbered tracts, harvests them, and sells the land as smaller parcels.

- `index.html` is the page, served by GitHub Pages.
- `land-second-brain-starter.md` is the starter file you hand to your AI to set up the vault.
